# Security policy

Skills in this repository can run scripts on your machine, so please report anything that could harm users.

## Report a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/linogics/ai-context/security/advisories/new). Do not open a public issue.

Include the affected plugin and version, steps to reproduce and the impact. You will get a reply within 7 days.

## Supported versions

Only the latest version of each plugin gets fixes.
